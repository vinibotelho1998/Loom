Contas

          

            Cada conta tem a propria pasta de login, entao varias ficam logadas ao mesmo tempo e voce
            troca sem deslogar. Remover a conta daqui nao mexe na conta la no provedor,
            so tira o login desta maquina.
          

          

          

            
            
          

        


        

          
Ferramentas

          

            Cada CLI guarda o login numa pasta apontada por uma variavel de ambiente.
            O DBX Term so precisa saber o nome dessa variavel e o arquivo que indica login feito.
            Claude Code esta confirmado nesta maquina. Os outros vem preenchidos com o valor
            documentado por cada projeto e podem ser corrigidos aqui se mudarem.
