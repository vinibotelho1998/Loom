Contas

Cada conta tem a própria pasta de login, então várias ficam logadas ao mesmo tempo. Remover daqui só tira o login desta máquina, a conta no provedor continua.

Ferramentas

Cada CLI guarda o login numa pasta apontada por uma variável de ambiente. O Loom só precisa do nome dela e do arquivo que indica login feito. Dá pra corrigir aqui se mudar.
