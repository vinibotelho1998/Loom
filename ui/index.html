Uso

Contas

Cada conta tem a própria pasta de login, então várias ficam logadas ao mesmo tempo e você troca sem deslogar. Remover a conta daqui não mexe na conta lá no provedor, só tira o login desta máquina.

Ferramentas

Cada CLI guarda o login numa pasta apontada por uma variável de ambiente. O Loom só precisa saber o nome dessa variável e o arquivo que indica login feito. Cada linha diz se o comando foi encontrado nesta máquina. Os valores vêm do que cada projeto documenta e podem ser corrigidos aqui se mudarem.
